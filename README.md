<details>
<summary><b>🗺️ My ML project checklist</b></summary>


1. Define the problem — decide what a useful result looks like.
2. Understand the data — inspect quality, missing values and assumptions.
3. Create a baseline — start simple and establish a reference score.
4. Experiment carefully — fit preprocessing on training data and track changes.
5. Evaluate honestly — select suitable metrics and inspect failure cases.
6. Build an interface — make the model usable through an application or API.
7. Document and improve — explain limitations and make the work reproducible.
</details>
